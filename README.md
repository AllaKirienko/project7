# Bank Widget

## Описание проекта

Проект представляет собой банковский виджет для обработки информации о банковских операциях.

В проекте реализованы функции:

- маскировки номеров банковских карт и счетов;
- форматирования дат;
- фильтрации операций по статусу;
- сортировки операций по дате;
- обработки данных с помощью генераторов.

## Модуль generators

Модуль `generators` предназначен для обработки большого количества данных транзакций с помощью генераторов Python.

В модуле реализованы функции:

- `filter_by_currency` — возвращает операции с указанной валютой;
- `transaction_descriptions` — возвращает описания операций по очереди;
- `card_number_generator` — генерирует номера банковских карт в заданном диапазоне.

## Примеры использования

### Фильтрация операций по валюте

Функция `filter_by_currency` позволяет получить только те транзакции, у которых валюта соответствует заданной.

```python
usd_transactions = filter_by_currency(transactions, "USD")

for transaction in usd_transactions:
    print(transaction)
```

### Получение описаний операций

Функция `transaction_descriptions` возвращает описание каждой операции по очереди.

```python
descriptions = transaction_descriptions(transactions)

for _ in range(5):
    print(next(descriptions))
```

### Генерация номеров банковских карт

Функция `card_number_generator` создает номера карт в заданном диапазоне в формате:

`XXXX XXXX XXXX XXXX`

Пример:

```python
for card_number in card_number_generator(1, 5):
    print(card_number)
```

Результат:

```
0000 0000 0000 0001
0000 0000 0000 0002
0000 0000 0000 0003
0000 0000 0000 0004
0000 0000 0000 0005
```

## Декоратор log

В проект добавлен декоратор `log`, который позволяет автоматически
отслеживать выполнение функций.

Декоратор поддерживает два режима работы:

- вывод информации о выполнении функции в консоль;
- запись информации в указанный файл.

Пример использования:

```python
@log(filename="mylog.txt")
def my_function(x, y):
    return x + y
```

При успешном выполнении функции в лог записывается:

```
my_function ok
```

При возникновении ошибки:

```
my_function error: Тип ошибки. Inputs: (аргументы), {}
```

Декоратор сохраняет информацию об имени функции, результате выполнения и параметрах при ошибке.
